# ToB 客户智能分级与销售情报系统

> 面向全行业（企业 / 医院 / 学校 / 政府）的 ToB 销售智能系统，构建"**数据评分 + AI 尽调 + 销售跟进**"三层闭环：
> 用 10 维 AHP 模型从客户名单中筛出高价值目标，用 AI 联网搜索做单客户深度尽调，销售跟进数据实时回写并重新评级。

## 一、项目背景

ToB 销售的三大核心问题：**找客户**（市场上谁值得跟）、**懂客户**（锁定后怎么打）、**跟客户**（接触过程中信息如何沉淀并反哺决策）。
本系统覆盖从客户筛选到深度尽调到销售跟进的完整闭环，同时支持**增量场景**（客户还没有系统，需要开拓）和**存量场景**（客户已有竞品，需要替换抢单）。

## 二、系统架构

```
客户基础数据（公开渠道：企查查/政府采购网/招聘网站/行业名录）
        +
销售跟进数据（手动维护：合作阶段/现有供应商/竞争态势/客户抱怨）
        ↓ 两路数据合并
10 维度 AHP 层次分析法评分（客户价值 / 成交可行性 / 客户需求度）
        ↓
A / B / C / D 四级分级
        ↓ Tavily 12 维 advanced 联网搜索（新闻/采购/供应商/竞品 等）
        ↓ DeepSeek 大模型综合分析（结合评分结果，围绕低分维度深挖）
单客户 9 段深度尽调报告（IT现状/竞争态势/30-60-90天行动计划/破冰话术）
        ↓
销售跟进记录回写 → 自动重新评级 → 闭环迭代
```

## 三、核心功能

### 1. 10 维全行业 AHP 评分模型

- **三大类权重**：客户价值 37.5% / 成交可行性 25.0% / 客户需求度 37.5%
- **10 个评分维度**：

| 大类 | 维度 | 全局权重 |
|------|------|----------|
| 客户价值 | 组织规模 | 9.0% |
| 客户价值 | 预算能力 | 13.2% |
| 客户价值 | 增长潜力 | 9.0% |
| 客户价值 | 战略价值 | 6.2% |
| 成交可行性 | 决策链复杂度 | 7.1% |
| 成交可行性 | 合作成熟度 | 10.7% |
| 成交可行性 | 竞争与替换成本 | 7.1% |
| 客户需求度 | 显性需求信号 | 12.0% |
| 客户需求度 | **降本增效与替换潜力** | **17.2%（第一权重）** |
| 客户需求度 | 行业需求刚性 | 8.3% |

- **AHP 一致性检验**：4 个判断矩阵全部通过（CR 最大 0.0013，远低于 0.1 阈值）
- **全行业支持**：企业 / 医院 / 学校 / 政府，分行业采用不同规模指标（企业用员工/营收，医院用床位，学校用学生数，政府用行政级别）
- **双场景覆盖**：增量客户（无系统，开拓新需求）和存量客户（有竞品，替换抢单）
- **分级阈值**：A ≥ 70 / B ≥ 60 / C ≥ 50 / D < 50

### 2. AI 联网深度尽调

- **12 维搜索**：公司背景、最新动态（近6个月）、组织架构、关键决策人、IT 现状与供应商、采购与预算信号（近6个月）、行业政策与痛点、财务与经营、竞品与市场格局、融资与资本动态、技术投入与研发、客户与上下游生态
- **搜索质量**：Tavily advanced 深度、时间过滤、URL 全局去重、每条截取 1500 字
- **9 段报告结构**：
  1. 客户评分概览与尽调重点（结合内部评分，围绕低分维度深挖）
  2. 公司概况与行业地位
  3. 最新动态与业务风向
  4. 组织架构与关键决策人
  5. IT 现状与现有供应商（销售最关心）
  6. 财务与经营分析
  7. 需求与痛点分析
  8. 竞争态势与替换机会（销售最关心）
  9. 销售策略与行动建议（含 30/60/90 天计划 + 破冰话术 + 首封邮件草稿）
- **销售情报联动**：销售跟进表中的合作阶段、现有供应商、客户抱怨等一手情报优先级最高，与联网情报冲突时以销售情报为准

### 3. 销售跟进管理

- 销售每次跟进追加一行记录，30 秒可填完
- 跟进字段：合作成熟度阶段、现有供应商名称、绑定程度、竞争激烈程度、客户抱怨现有产品、是否行业标杆、行业排名、跟进日期、备注
- 新客户导入自动填默认值，销售零负担
- 跟进记录保存后自动回写客户数据并重新评级
- 支持单条新增和 CSV 批量导入

### 4. 客户导入与批量评级

- CSV 模板批量导入客户名单（34 个字段，含 5 条全行业示例数据）
- 导入后自动套用 10 维 AHP 模型即时打分分级
- 支持追加到现有客户库

### 5. 可视化看板

- 客户评分总览：分级分布、行业分布、评分分布、维度贡献分析
- 客户详情：单客户 10 维评分雷达图、维度贡献、与行业平均对比
- 客户列表：筛选、搜索、导出
- 数据来源与架构说明

## 四、技术栈

| 层 | 技术 |
|----|------|
| 评分模型 | NumPy（AHP 特征向量法 + 一致性检验） |
| 数据处理 | Pandas |
| AI 应用 | DeepSeek LLM, Tavily Search API |
| 可视化 | Streamlit, Plotly |

## 五、项目结构

```
customer_scoring/
├── src/
│   ├── ahp_weights.py          # AHP 权重模块（4个判断矩阵 + 特征向量法 + CR检验）
│   ├── scoring_model.py        # 10维评分模型（全行业支持 + 销售跟进合并 + 旧数据兼容）
│   └── company_researcher.py   # AI联网深度尽调（12维搜索 + 9段报告 + 评分联动）
├── data/
│   ├── customer_import_template.csv  # 客户导入模板（34字段 + 5条示例）
│   ├── our_products.csv             # 本公司产品库
│   └── sales_followup.csv           # 销售跟进记录
├── outputs/                     # 评分结果
├── research_reports/            # AI尽调报告（含原始情报JSON）
├── app.py                       # Streamlit 可视化看板
├── requirements.txt
├── .env                         # API Key（不提交到Git）
└── README.md
```

## 六、快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置 API Key（在项目根目录新建 .env 文件）
# TAVILY_API_KEY=你的key
# DEEPSEEK_API_KEY=你的key

# 3. 导入客户数据
# 将客户名单按 data/customer_import_template.csv 格式整理，放入 data/ 目录

# 4. 启动看板
streamlit run app.py
```

## 七、数据来源与免责声明

- **客户基础数据**：企查查/天眼查（企业信息+财务）、政府采购网（采购公告+历史中标）、招聘网站（IT岗位）、卫健委/教育部名录（医院床位/学校学生数）——自动爬虫待实现，目前通过 CSV 手动导入
- **销售跟进数据**：销售手动维护
- **AI 尽调数据**：Tavily 联网搜索（公开新闻、官网、招投标平台等）
- 所有数据均来自公开渠道，AI 分析基于公开信息推断，仅供学习研究与内部销售参考，不构成投资或销售决策依据
